# Telegram AI Image Generator Bot

بوت Telegram يحوّل الوصف النصي (عربي / English / Français) إلى صورة عبر **Pollinations** ويُشغَّل عبر **GitHub Actions**.

## ⚠️ حقائق مهمة (بلا مبالغة)
- **لا توجد خدمة توليد صور "لا نهائية" حقيقية.** المشرف (أنت) غير مقيّد بحصص البوت، لكن مزوّد الصور يحتسب استهلاكاً من رصيده (Pollen). عند نفاد الرصيد سيُبلّغك البوت.
- لم أتمكن من التحقق من مقدار الرصيد المجاني الحالي من الوثائق الرسمية؛ راجع حسابك في https://enter.pollinations.ai لمعرفة رصيدك وحدودك.
- **GitHub Actions ليس استضافة 24/7**: كل مهمة تعمل بحد أقصى 6 ساعات. هذا المشروع يشغّل البوت ~5 ساعات و45 دقيقة ثم تبدأ مهمة جديدة كل 6 ساعات (cron)، فتحدث **فجوة قصيرة (~10 دقائق) تتأخر فيها الردود** (الرسائل لا تضيع؛ Telegram يحتفظ بها ويعالجها بعد العودة).
- الدقائق مجانية للمستودعات **العامة (Public)** على المشغّلات القياسية. المستودع الخاص له حد شهري محدود ولن يكفي للتشغيل المستمر.
- GitHub قد يعطّل الجدولة تلقائياً بعد 60 يوماً بلا نشاط في المستودع العام؛ إذا توقف البوت شغّله يدوياً (Run workflow).
- قاعدة البيانات تُحفظ بين التشغيلات عبر Actions cache (أفضل جهد): قد تُفقد إن حُذف الكاش (يُحذف بعد 7 أيام بلا استخدام). المستخدمون والحصص قد تُصفَّر في هذه الحالة.
- سجلات Actions في مستودع عام **تظهر للجميع**؛ البوت لا يطبع المفاتيح ولا نصوص المستخدمين.

## البنية
```
bot.py            البوت والأوامر
config.py         قراءة المتغيرات من البيئة
image_provider.py محرك الصور (قابل للتبديل)
database.py       SQLite: مستخدمون، حصص، إعدادات
admin.py          أمر /admin للمشرف فقط
requirements.txt
.github/workflows/bot.yml
```

## الخطوة 0: أمان التوكن
إذا نشرت توكن البوت في أي محادثة، اعتبره مكشوفاً: افتح @BotFather ← `/revoke` ← اختر البوت ← احصل على توكن جديد.

## الخطوة 1: معرفة ADMIN_ID
افتح @userinfobot في Telegram وأرسل أي رسالة؛ سيعطيك **رقمك (Id)**. هذا هو `ADMIN_ID`.
(رقم البوت ليس رقمك؛ لا تستخدمه.)

## الخطوة 2: مفتاح الصور
1. من متصفح الهاتف افتح https://enter.pollinations.ai وسجّل الدخول.
2. أنشئ مفتاحاً سرياً (يبدأ بـ `sk_`) — هذا هو `IMAGE_API_KEY`. لا تشاركه.

## الخطوة 3: رفع المشروع إلى GitHub من الهاتف
1. افتح github.com في المتصفح (فعّل "نسخة سطح المكتب" إن لزم) وأنشئ حساباً.
2. **New repository** ← اسمه `telegram-image-bot` ← اختر **Public** ← Create.
3. فك ضغط ملف ZIP بتطبيق "الملفات" في أندرويد.
4. في المستودع: **Add file ← Upload files** وارفع: `bot.py config.py image_provider.py database.py admin.py requirements.txt README.md .gitignore` ثم Commit.
5. ملف الـ workflow (المجلدات المخفية قد لا تظهر عند الرفع): **Add file ← Create new file**، واكتب في خانة الاسم بالضبط:
   `.github/workflows/bot.yml`
   ثم الصق محتوى `bot.yml` وCommit.

## الخطوة 4: إضافة الأسرار
المستودع ← **Settings ← Secrets and variables ← Actions ← New repository secret**. أضف ثلاثة أسرار بهذه الأسماء بالضبط:
- `TELEGRAM_BOT_TOKEN` — توكن البوت من BotFather
- `IMAGE_API_KEY` — مفتاح Pollinations
- `ADMIN_ID` — رقمك

## الخطوة 5: التشغيل والاختبار
1. تبويب **Actions** ← فعّل الـ workflows إن طُلب.
2. اختر **Run Telegram bot** ← **Run workflow**.
3. افتح التشغيل وتأكد من ظهور `Bot started` في السجل.
4. في Telegram أرسل `/start` ثم وصفاً مثل: `a red fox in the snow`.
5. أرسل `/admin` لترى لوحة المشرف.

## أوامر المستخدم
`/start` `/help` `/generate <وصف>` `/settings` (النسبة 1:1 / 16:9 / 9:16 والأسلوب: Auto / Photo / Cinematic / Art / Design) — أو أرسل الوصف مباشرة.

## أوامر المشرف (أنت فقط)
`/admin stats` · `pause` · `resume` · `model <اسم>` · `limit <عدد>` · `maxlen <عدد>` · `ban <id>` · `unban <id>`

## تعديل الإعدادات لاحقاً
- النموذج/الحد اليومي/طول الوصف: من `/admin` مباشرة (تُحفظ في قاعدة البيانات).
- النموذج الافتراضي أول مرة: أضف `IMAGE_MODEL: flux` ضمن `env:` في `bot.yml`. أسماء النماذج المتاحة موجودة في وثائق Pollinations؛ إذا أدخلت اسماً غير مدعوم سيرد المزوّد بخطأ.
- مهلة الطلب `REQUEST_TIMEOUT` وعدد التوليدات المتزامنة `MAX_CONCURRENT` يمكن إضافتهما بنفس الطريقة.
- تبديل المزوّد: أضف صنفاً جديداً في `image_provider.py` وسجّله في `build_provider()`.

## حدود الاختبار
تم التحقق من صحة صياغة Python وملف YAML ومنطق قاعدة البيانات محلياً. **لم يُختبر** الاتصال الفعلي بـ Telegram ولا بـ Pollinations (لا يوجد وصول للشبكة في بيئة الإنشاء)، لذا أول تشغيل هو الاختبار الحقيقي. إن ظهر خطأ في سجل Actions أرسله لي (دون أي مفاتيح).
