Telegram AI Image Generator Bot
بوت Telegram يحوّل الوصف النصي (عربي / English / Français) إلى صورة عبر Pollinations ويُشغَّل عبر GitHub Actions.
⚠️ حقائق مهمة (بلا مبالغة)
لا توجد خدمة توليد صور "لا نهائية" حقيقية. المشرف (أنت) غير مقيّد بحصص البوت، لكن مزوّد الصور يحتسب استهلاكاً من رصيده (Pollen). عند نفاد الرصيد سيُبلّغك البوت.
لم أتمكن من التحقق من مقدار الرصيد المجاني الحالي من الوثائق الرسمية؛ راجع حسابك في https://enter.pollinations.ai لمعرفة رصيدك وحدودك.
GitHub Actions ليس استضافة 24/7: كل مهمة تعمل بحد أقصى 6 ساعات. هذا المشروع يشغّل البوت ~5 ساعات و45 دقيقة ثم تبدأ مهمة جديدة كل 6 ساعات (cron)، فتحدث فجوة قصيرة (~10 دقائق) تتأخر فيها الردود (الرسائل لا تضيع؛ Telegram يحتفظ بها ويعالجها بعد العودة).
الدقائق مجانية للمستودعات العامة (Public) على المشغّلات القياسية. المستودع الخاص له حد شهري محدود ولن يكفي للتشغيل المستمر.
GitHub قد يعطّل الجدولة تلقائياً بعد 60 يوماً بلا نشاط في المستودع العام؛ إذا توقف البوت شغّله يدوياً (Run workflow).
قاعدة البيانات تُحفظ بين التشغيلات عبر Actions cache (أفضل جهد): قد تُفقد إن حُذف الكاش (يُحذف بعد 7 أيام بلا استخدام). المستخدمون والحصص قد تُصفَّر في هذه الحالة.
سجلات Actions في مستودع عام تظهر للجميع؛ البوت لا يطبع المفاتيح ولا نصوص المستخدمين.
